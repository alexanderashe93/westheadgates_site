Build spec

Technical SEO

What goes into every page, and what has to be built once. The site already ships some of this — marked done below.

1 · Every page’s <head>

<title>Electric Gates [Town] | Westhead Gates</title> ← under 60 chars, keyword first, brand last <meta name="description" content="…"> ← 150–160 chars, written to earn the click <link rel="canonical" href="https://…/services/electric-gates/"> <meta property="og:title" …> <meta property="og:image" …> ← a real photo, 1200×630 <script type="application/ld+json"> { … } </script>

Titles and descriptions must be unique on every page. Duplicates are the fastest way to have pages ignored. The four existing pages already carry all of this.

2 · Structured data

This is what turns a plain blue link into a result with stars, prices and expandable questions.

LocalBusinessHome page. Name, address, phone, hours, area served, geo coordinates. Already on the home page — needs the real details filling in.
ServiceEach of the six service pages. Ties the service to the business and the area.
FAQPageEvery page with an FAQ. Wins “People also ask” slots and expandable results.
BreadcrumbListEvery page below the home page. Shows the path in the result instead of a raw URL.
ImageObjectGallery photos. Generated automatically from the folder scan — no extra work per photo.
Review / AggregateRatingOnly with genuine, verifiable reviews. Faking these gets a manual penalty, so it is real ones or none.

3 · Images — where the gallery pays off

The folder scanner already turns filenames into captions. The same mechanism gives every photo proper alt text, so naming files well is the SEO work — there is no separate admin step.

images/driveway-gates/oak-clad-electric-gates-ormskirk.jpg ↓ alt="Oak clad electric gates, Ormskirk" + caption + ImageObject schema
Width & height read from the file — no layout shift (done)
Lazy loading below the fold (done)
Auto-generate WebP + thumbnails on upload
Image sitemap, generated from the same scan

4 · Technical foundations

SitemapGenerated by PHP from the real page list, so it can never drift out of date. Currently hand-written for four pages.
URLsLower-case, hyphenated, no extensions: /services/electric-gates/ (.htaccess already strips .html)
HTTPS + HSTSForced redirect. Already in .htaccess — uncomment once the certificate is installed.
Core Web VitalsNo framework, no render-blocking JS, fonts preconnected. Should pass out of the box — verify with PageSpeed Insights after launch.
Search ConsoleVerify the domain, submit the sitemap, then actually read it monthly. This is where you learn what people really search.
AnalyticsSomething privacy-light. Track quote form submissions and phone-link taps as conversions, not just page views.

5 · The part that isn’t the website

For a local trade, on-page SEO is maybe a third of the result. Being straight with you: if you only do one thing from this page, do the first item.

Google Business ProfileClaim it, complete every field, add photos weekly, answer questions. This is what wins the map pack, which sits above every organic result.
ReviewsAsk every satisfied customer, every time. Volume and recency both count. A steady trickle beats a burst.
Consistent NAPName, address and phone identical everywhere — site, GBP, Checkatrade, Yell, Facebook. Mismatches dilute you.
Local linksTrade bodies, suppliers, the local paper, anyone you have done work for. A handful of genuine local links beats a hundred bought ones.

6 · Suggested build order

01

Foundations

Shared header/footer includes, auto sitemap, schema helper. One day’s work that makes the other 24 pages cheap.

02

Six service pages

Highest commercial intent. These are what turn searches into quotes.

03

Town pages

Only for towns where you have a real job and real photos. Start with three.

04

Guides, ongoing

One a month. This is the part that compounds — and the part everyone abandons.

On timescales: a new site on a new domain takes [6–12] months to rank for competitive local terms, and no amount of on-page work shortcuts that. Anyone promising page one in six weeks is selling something. The pages built now are what start the clock.
